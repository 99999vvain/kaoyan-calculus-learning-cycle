# 数据文件格式规范（写入前必读）

## 0. 数据目录

```
DATA_DIR = <skill 目录>/data/
```

含四个文件 + 一个备份目录：

| 文件 | 唯一职责 | 写入方式 |
|---|---|---|
| `学习进度.md` | 状态快照 + 知识点台账 + 应试能力记录 | 快照整段重写；台账只加行/改 4 列；应试表只加行 |
| `错题档案.md` | 错题台账与复测记录 | 只加行；复测记录单元格追加 |
| `每日学习记录.md` | 按日追加的学习块 | 只追加 `## 日期` 块 |
| `讲义索引.md` | 讲次 ↔ 知识点对照 | 只加行 |
| `backup/` | 手动/月度备份 | 只在你要求或每月首日复制 |

首次初始化时，四个文件从 `assets/templates/` 同名空白文件复制，不要自行现编表头（脚本依赖固定表头）。

**更新 skill 前必须先复制 `data/` 到 `data/backup/`**，否则模板覆盖可能导致数据丢失。

---

## 1. 全局取值约定

| 记号 | 取值 | 说明 |
|---|---|---|
| 知识点 ID | `K-章.节.序`，如 `K-3.2.1` | 必须从 `knowledge-map.md` 复制，不得自造 |
| 错题 ID | `E-0001` 递增四位 | 全局唯一，不按日期重置 |
| G | `G1` / `G2` / `G3` | 教学档位 |
| D | `D1` / `D2` / `D3` / `D4` | 单值，不写区间，不写 `D2.5` |
| B | `B1` / `B2` / `B3` / `B4` | 单值 |
| 状态 | `未开始` `在学` `已学待验` `待复习` `复习中` `已掌握` `需回炉` | 只有这七个 |
| 计时来源 | `手动` / `自动` / `未记录` | 时长类字段必须配来源，禁止只写分钟不写来源 |
| 日期 | `YYYY-MM-DD` | 一律取系统时间，禁止写"昨天/上周" |
| next_review | `YYYY-MM-DD` 或 `-` | `-` 表示不再排期 |
| 空值 | `-` | 不留空白，不写 `N/A`、`无` |
| 表格禁用字符 | 竖线符号、换行符 | 题干用文字描述，如"x 乘 e 的 x 次方" |

## 2. `学习进度.md`

### 2.1 结构（顺序固定，不得调换）

```
# 学习进度（考研数学一 · 高等数学）

## 状态快照
（9~10 个键，全文唯一，见 assets/snapshot-template.md）

## 知识点台账
（表格）

## 应试能力记录
（表格）
```

### 2.2 状态快照块

- 位置：文件最上方，`# 标题` 之后。
- 唯一性：全文只能出现一次。重写时替换整段，不要新增第二段。
- 必填键：见 `assets/snapshot-template.md`，缺一即视为不完整。
- **待复测** 格式：`E-0001(2026-10-24)｜K-3.2.1(2026-10-22)`；无则写 `-`；最多列 5 项，超出写 `...等N项`（明细在台账里）。

### 2.3 知识点台账

```
| ID | 章节 | 知识点 | G | D | B | 掌握证据 | 证据日期 | 状态 | next_review |
|---|---|---|---|---|---|---|---|---|---|
```

| 列 | 取值规则 |
|---|---|
| ID | 来自 knowledge-map |
| 章节 | 如 `3.2 不定积分` |
| 知识点 | 中文名，与 map 一致 |
| G / D / B | 枚举单值；未评估写 `-` |
| 掌握证据 | `动作+数量+结果(+错因)`；无证据写 `-` |
| 证据日期 | `YYYY-MM-DD`；无写 `-` |
| 状态 | 七枚举 |
| next_review | 日期或 `-` |

**允许的修改**：①追加行；②原地修改 `掌握证据 / 证据日期 / 状态 / next_review` 四列。
**禁止**：重排、合并、删除历史行；改 ID；把 G/D/B 改成非枚举值。

### 2.4 应试能力记录

```
| 日期 | 知识点ID | 题型 | 题量 | 限时 | 实际用时 | 用时来源 | 正确 | 失分原因 |
|---|---|---|---|---|---|---|---|---|
| 2026-10-21 | K-2.3.1 | 解答 | 2 | 7min | 9min | 手动 | 1/2 | 计算性:漏系数 |
```

- `题型` 只能取 `选择 / 填空 / 解答`；一题多问按主问法记。
- `限时`/`实际用时` 必须同时填；实际用时未获得时写 `-`，`用时来源` 写 `未记录`。
- `用时来源` 只能取 `手动 / 自动 / 未记录`；**不得把估出来的时间写成 `手动`**。
- `正确` 写 `n/m`。
- `失分原因` 取五分类，多条用 `；` 分隔，每条附 6 字内描述；全对写 `-`。
- **本表不参与 D/B 计算**，任何汇总不得反推掌握度。

## 3. `错题档案.md`

### 3.1 文件头（勿删）

```
## 字段约定（勿删本节）
- 错误类型：概念性 / 方法性 / 计算性 / 审题性 / 时间性（主因在前，可多选）
- 状态：待复测 / 已复测未过 / 已复测通过 / 已归档
- next_review：YYYY-MM-DD；复测通过按 1→3→7→21 天推进；连续两次通过 → 已归档，next_review 记 -
```

### 3.2 台账

```
| ID | 首次日期 | 知识点ID | 题目摘要(≤30字) | 我的做法/卡点 | 正确思路(≤40字) | 错误类型 | 补救动作 | next_review | 复测记录 | 状态 |
|---|---|---|---|---|---|---|---|---|---|---|
```

| 列 | 规则 |
|---|---|
| 题目摘要 | ≤30 字，只写识别特征（"∫x·e^x dx 用换元做"） |
| 我的做法/卡点 | 写具体错误动作，不写"不会" |
| 正确思路 | ≤40 字，写方法与关键一步 |
| 错误类型 | 五分类，主因在前 |
| 补救动作 | 只能取自 `teaching-rules.md` 第 4 节 |
| 复测记录 | 追加串：`2026-10-24 通过；2026-10-27 通过`，不改历史 |
| 状态 | 四枚举 |

### 3.3 复测推进规则

| 当前 | 复测通过 | 复测未过 |
|---|---|---|
| next_review 距今天数 | 1→3→7→21 递进：按下一个间隔排 | 回到 1 天，状态 `已复测未过` |
| 连续两次通过 | 状态 `已归档`，next_review 记 `-` | — |

逾期超过 7 天：只提示一次，不惩罚、不记欠账。

## 4. `每日学习记录.md`（只追加）

每个学习日一个块，**14 个 bullet 标签固定**，缺失写 `未记录`：

```
## 2026-10-21 · 35min · 第2章 2.3 高阶导数
- 可用/实际：35min / 40min
- 计时来源：手动
- 今日目标：
- 范围：
- 前置：
- 计划：
- 达标标准：
- 过程：
- 效果检验：
- 维度变化：
- 产生错题：
- 未完成：
- 未完成原因：
- 下次建议：
```

- `计时来源` 只能取 `手动 / 自动 / 未记录`；**你未报告时间就写 `未记录`，不许估**。
- `未完成原因` 取 `coaching-rules.md` 第 2 节的六分类之一（时间不足/难度过高/计划过载/外部打断/主动放弃/未记录）。
- 同一天多次学习：追加第二个 `## 2026-10-21 · …` 块，不合并改写。
- 修正历史：追加一行 `- 更正(2026-10-22)：……`，**不改旧行**。
- 文件变长后，下次会话只读**最后一个块**，不全文读。

## 5. `讲义索引.md`

```
| 收到日期 | 讲次/标题 | 页码范围 | 覆盖知识点ID | 本讲例题数 | 讲义强调点 | 备注 |
|---|---|---|---|---|---|---|
```

- 覆盖知识点多个用 `；` 分隔。
- 本讲例题数只记数字。
- 读不出讲次时该列写 `-`，并在备注写 `讲次未识别`，不许猜。
- **页码范围列只写书上印刷的页码**，并标注来源：`P51-P58（印刷页）` / `P51-P58（封面标注）` / `P51-P58（用户确认 YYYY-MM-DD）`。禁止用 PDF 顺序页冒充印刷页（见 `handout-intake.md` 第 2.5 节）。

## 6. 写入白名单（最高优先级约束）

只允许以下四种写入动作：

| # | 动作 | 位置 |
|---|---|---|
| 1 | 追加表格行 | 四个文件的表格末尾 |
| 2 | 原地修改四列 | 台账 `掌握证据/证据日期/状态/next_review` |
| 3 | 整段重写快照块 | `学习进度.md` 的 `## 状态快照` 段 |
| 4 | 追加单元格串 | 错题档案 `复测记录` |

**一律禁止**：重写整个文件、删除行、合并行、调整列顺序、改历史日期、把表格改成列表。

### 写入失败的处理（必须执行）

写入失败（权限被拒 / 文件被占用 / 内容格式异常 / 工具报错）时：

1. **当场告知**：说明哪个文件、失败原因、哪些内容没有写进去；
2. **给出补救**：把未写入的内容原样列在对话里，供你手工保存或下次重试；
3. **不得**说"已记录""已更新"；不得静默跳过；不得用"大概写好了"带过；
4. 重试一次仍失败 → 停止重试，避免反复覆盖。

## 7. 上下文控制

每次会话读数据只读三处，避免把历史全量读入：

1. `学习进度.md` 的 `## 状态快照` 段（10 行左右）；
2. `学习进度.md` 台账中**当前章节**的行；
3. `每日学习记录.md` 的**最后一个** `## 块`。

到期复测清单由 `scripts/due_review.py` 输出，不靠全量读表。

---

## 8. 一致性自检（每次写完执行）

| 检查项 | 方法 |
|---|---|
| 表格列数一致 | 每个新行的竖线数量与表头相同 |
| ID 存在 | 新行 ID 能在 knowledge-map 找到 |
| 日期格式 | 全部 `YYYY-MM-DD`，无中文日期 |
| 状态枚举 | 只出现七个合法值 |
| 计时来源 | 有分钟数的行必须同时有 `手动/自动` 来源；否则写 `未记录` |
| 计划与实际分开 | 每日块 `可用/实际` 不得只写一个数；`计划` 与 `过程` 不得混为一行 |
| D/B 无复合值 | 不出现 `%`、`D2.5`、`G2+` |
| 快照与台账一致 | 快照的当前知识点/梯度 = 台账对应行 |
| 未完成任务同步 | 快照 `未完成任务` 与最后一个每日块的 `未完成` 一致 |
