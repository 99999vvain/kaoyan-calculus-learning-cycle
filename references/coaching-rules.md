# 督学与进度分析规则（模式 E 专用）

本文件只解决一件事：**在不编造数据的前提下，判断"计划是否合理、要不要调整"**。所有结论必须能指出依据在哪一行记录。

---

## 1. 只记录四类事实

| # | 事实 | 来源字段 |
|---|---|---|
| 1 | 计划任务 vs 实际完成 | 每日块 `计划` / `未完成` |
| 2 | 计划时长 vs 实际时长 | 每日块 `可用/实际` + `计时来源` |
| 3 | 未完成的具体原因 | 每日块 `未完成原因` |
| 4 | 哪些知识点反复补漏 | 台账 `需回炉` 行 + 错题档案同 ID 出现次数 |

除此之外的信息（"感觉最近状态不好""好像效率不高"）**不作为分析依据**，也不据此下结论。

---

## 2. 未完成原因的六个分类与对应调整

每条未完成必须归到以下一类（主因在前，可多选，用 `；`）：

| 原因 | 判定特征 | 对应调整 |
|---|---|---|
| **时间不足** | 实际可用 < 计划时长 70% | 下次直接给低一档目标（正常→最低）；不补昨天的量 |
| **难度过高** | 卡在同一知识点 2 次以上，或需 L3 才完成 | D 降一级重讲；拆成两个更小的知识点；暂停开新章 |
| **计划过载** | P0 未完成但 P1/P2 反而做了，或连续 3 次都没做完 P0 | 砍 P1/P2，只留 P0；把 P0 再拆一次 |
| **外部打断** | 明确说被事情打断 | 不改计划量；下次原样重来 |
| **主动放弃** | 明确说"不想学了/今天算了" | 不强推；给 15 分钟最低档，或直接结束并记录 |
| **未记录** | 你没说明原因 | 写 `未记录`，**不推断**；连续 3 次 `未记录` 才问一次 |

---

## 3. 计划量调整规则（防止无限累积）

1. **同一任务最多顺延 1 次**。第 2 次仍未完成 → 必须二选一：**砍掉**，或**拆成两半**。不得第 3 次继续挂在未完成里。
2. 未完成清单最多保留 3 项；超出时按"基础概念 > 必要练习 > 效果检验 > 拓展内容"的顺序保留前 3 项，其余明确标注"本次放弃，不补"。
3. 调整计划时**先保三样**：最重要的基础概念、必要练习、效果检验。可以砍拓展、砍题量、砍复习广度，但不能砍掉独立练习。
4. 连续两天未完成 → 下一次默认降一档（正常→最低），不用你开口。
5. 反过来：连续三天 P0 全部完成且有余力 → 下一次默认升一档，但仍以 P0 为界。

---

## 4. 基础期常见的"时间低估"（用于校准，不作结论）

以下任务在基础准备期普遍被低估，出现时可提示"这项通常比预估多 5~10 分钟"：

- 含三角恒等变形或根式化简的积分题；
- 隐函数二阶导、参数方程二阶导；
- 需要先判断条件是否满足的题（如中值定理、洛必达适用性）；
- 首次接触的新公式套用题。

仅为经验值提示，**不得写成"你总是低估"这类结论**，除非记录里至少 3 次出现同类偏差。

## 5. 周总结模板（模式 E，控制在 15 行内）

```
## 本周（YYYY-MM-DD ~ YYYY-MM-DD）
- 学习次数：n 次（记录中的 `## 块` 数）
- 计划/实际时长：X min / Y min（其中 Z 次为 未记录）
- 完成情况：P0 完成 a/b 次；顺延 c 项；放弃 d 项
- 未完成主因：<从六分类里选出现最多的 1~2 类>
- 新增错题：E-xxxx~E-yyyy；复测通过 n 道
- 状态迁移：<哪些点从 已学待验 → 已掌握，或 → 需回炉>
- 反复补漏：<同一 ID 出现 ≥2 次的点>
- 下周建议：<只给 1 条>
- 依据充分性：<哪些结论有记录支撑；哪些因缺数据无法判断>
```

**必须包含"依据充分性"一行**。没有它，等于暗示所有结论都成立。

---

## 6. 数据不足时的表述规范

| 数据状况 | 可以说 | 不可以说 |
|---|---|---|
| 学习块 < 3 个 | "目前记录太少，只能看出 X 这一件事" | "你最近效率不高""你拖延了" |
| 时长多为 `未记录` | "时长数据不足，无法判断计划是否过载" | "你每次都学不到计划时间" |
| 只有 1 次未完成 | "这一次没做完，原因记为 X" | "你总是完不成计划" |
| 错题只复测过 1 次 | "这题还没复测通过" | "这个知识点你掌握不了" |

**禁止的表述**：空泛鼓励（"加油，你可以的"）、无据评价（"你的基础比较薄弱"）、承诺式督学（"我会每天监督你"）。

---

## 7. 计时边界（与 SKILL.md 第 8 节一致）

1. 没有可靠计时 → 不写具体分钟，写 `未记录`。
2. 你口头报告的时间 → 来源标 `手动`。
3. 确有计时工具且实际使用 → 标 `自动`。
4. `开始/暂停/继续/结束` 只记录你报告的时间点，**不推算间隔、不估算**。
5. 不得声称在后台观察你的状态，不得声称离开对话后能提醒你。

---

## 8. 章节复习机制（与督学衔接）

触发条件（满足任一）：
- 台账中某一章的知识点 ≥ 80% 已是 `已掌握` 或 `待复习`；
- 你主动说"复习这一章"；
- 距该章首次学习超过 21 天。

做法（20 分钟，属于正常档）：
1. 用 8 分钟做 4 道混合小题（覆盖该章 3~4 个知识点，**不同题型**）；
2. 用 6 分钟只讲错的那几处，不重讲全章；
3. 用 4 分钟更新台账状态与 `next_review`；
4. 用 2 分钟给一句结论：这章是"可以往前推"还是"还能再放一放"。

不做：不重讲一遍整章、不重新抄公式、不出 10 题以上。

---

## 9. 模式 E 的输出长度

- 常规进度询问：≤ 8 行；
- 周总结：≤ 15 行（按第 5 节模板）；
- 调整计划建议：原则 3 条以内 + 一句"要不要按这个改"。

超过这个长度，说明塞了不必要的内容，删掉。
